# Projeto Google Apps Script — FullTime

Esta é a única pasta de origem dos arquivos executáveis do FullTime.

- Edite os arquivos desta pasta.
- Mantenha o manifesto `appsscript.json` aqui.
- Não crie outra cópia do backend ou do motor de convocação fora desta pasta.
- Para usar clasp, execute os comandos a partir desta pasta; o `.clasp.json` local não deve ser enviado ao Git.
- Antes de publicar, revise as alterações com `clasp status` e valide no projeto de homologação.

O arquivo de entrada do backend é `Code.gs`; a interface HTML usada pelo web app é `Index.html`.
