# FullTime — Google Apps Script

Esta é a única pasta oficial dos arquivos executáveis do projeto.

- Code.gs: backend principal (origem Código.js do backup atual).
- Index.html: interface web.
- MotorConvocacaoAutomaticaFullTime.gs: único motor ativo de convocação automática.
- Os demais arquivos .gs contêm os módulos de cadastro, autenticação, auditoria, escala, integrações, homologação, portal, solicitações e testes.
- ppsscript.json: manifesto do projeto.

Não copie arquivos da pasta docs/archive/ para o editor Apps Script. Ela contém versões históricas e cópias substituídas, guardadas apenas para auditoria.
O arquivo .clasp.json é local e não deve ser publicado no GitHub.
